Kelvin API

Your personal OpenAI-compatible API. The website talks only to Kelvin API — no third-party AI vendors on this server.

Base URL

https://kelvinoz.com/v1

Auth

Authorization: Bearer YOUR_KELVIN_API_KEY

Chat

curl https://kelvinoz.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KELVIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama3.2",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": false
  }'

Images

curl https://kelvinoz.com/v1/images/generations \
  -H "Authorization: Bearer YOUR_KELVIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"a red apple","size":"1024x1024"}'

Models

curl https://kelvinoz.com/v1/models \
  -H "Authorization: Bearer YOUR_KELVIN_API_KEY"

Your engine (required)

Kelvin API does not call OpenAI or NoMask. It only talks to your model server:

  • KELVIN_ENGINE_BASE_URL — e.g. http://YOUR_VPS_IP:11434/v1 (Ollama)
  • KELVIN_ENGINE_MODEL — e.g. llama3.2
  • KELVIN_IMAGE_ENGINE_URL — your image server OpenAI-compatible base (optional)
  • KELVIN_API_KEY — your personal API key

Quick Ollama on a VPS you own:

curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.2
# Ollama serves OpenAI-compatible API at :11434/v1
